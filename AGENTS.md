## Language

Use English for all project artifacts, including issue titles, descriptions and comments, documentation, code comments, commit messages, and pull request titles and descriptions.

## Commit messages

Use Conventional Commits for all commit messages: `<type>[optional scope]: <description>`
(for example, `feat: add VM SSH task` or `docs: update setup instructions`).

## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Domain docs

This repo uses a single-context domain documentation layout. See `docs/agents/domain.md`.
